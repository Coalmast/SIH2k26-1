  → PDF renders with environment-specific data (dust, SPM, water pH, EC conditions)

## How to Record the Demo

1. **Terminal 1**: Make sure your local database is freshly seeded.
2. **Terminal 2**: Have the backend, frontend, and mobile Expo server running.
3. **Web View 1 (Mine Manager)**: Navigate to the Compliance page and point out the 4 pending environmental tasks and the auto-generated banner.
4. **Mobile App**:
   - Open the app, go to the Notifications tab to show the "Compliance Task Assigned" notification.
   - Go to Inspections → Start a new **"Environmental Gas & Air Quality"** inspection at Section 3 East.
   - Enter readings that exceed the threshold (e.g., PM10 = 4.2). Submit the inspection.
5. **Trigger Critical Alert**:
   - In a terminal, run the following command to send an alert to the mobile device:
     ```bash
     python backend/test_notification.py 00000000-0000-0000-0000-000000000010 critical "🚨 CRITICAL: PM10 Critically High — Evacuate" "Respirable dust (PM10) recorded at 4.2 mg/m³, exceeding EC limit of 3.0 mg/m³. Section 3 East must be evacuated immediately."
     ```
   - *Ensure the user ID matches the logged-in inspector user.*
6. **Web View 2 (Safety Manager)**:
   - Navigate to the Alerts page to show the AI Risk Assessment panel and the escalated breach alert.
   - Go to Reports → Select "Half-Yearly EC Compliance Report" and "Umrer OCP" → Click "Auto-populate from System".
   - The PDF will render with the breach data. Proceed to digitally sign and submit the report.
